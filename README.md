# Tariff Scrape (资费套餐查询与对比工具)

**Tariff Scrape** 是一个基于 Node.js 开发的自动化资费套餐抓取与对比分析工具。它可以按省份查询不同运营商的套餐资费，自动将套餐分类为“主套餐”与“流量包”，并支持多省份横向对比分析，生成直观的文本报告与结构化数据。

## ✨ 核心特性

* **精准省份支持**：支持全国 31 个省市的定向查询（名称严格匹配网页）。
* **智能资费分类**：自动通过特征词，将抓取的数据精准划分为“主套餐”与“附加流量包”。
* **多省份横向对比**：当查询两个及以上省份时，自动生成详细的横向对比表格，并直接输出全场最低价结论。
* **灵活的数据导出**：支持导出为直观的文本报告（`.txt`）以及结构化数据（`.json`），便于二次分析。
* **常驻定时任务**：内置监听模式，支持自动循环执行；同时也完美兼容系统的定时任务调度。

## ⚙️ 参数选项与功能列表

运行 `node tariff-query.js` 时支持以下参数：

| 参数 | 功能描述 |
| --- | --- |
| `-p <省份名>` | 指定查询的省份（可多次使用，如 `-p 上海市 -p 江苏省`）。 |
| `--list-provinces` | 列出所有可选的 31 个省份（注意：输入的省份名称需与列表严格一致）。 |
| `--nationwide-only` | 只查询/显示全网通用的套餐。 |
| `--local-only` | 只查询/显示本省特有的套餐。 |
| `--top <N>` | 每类数据提取前 N 条记录（默认取前 8 条）。 |
| `--out <文件名>` | 将查询结果与对比报告输出到指定的文本文件（如 `report.txt`）。 |
| `--json` | 额外导出一份结构化的 JSON 文件。 |
| `--watch` | 开启常驻模式，默认每 12 小时自动执行一次抓取。 |
| `--interval <小时>` | 配合 `--watch` 使用，自定义循环执行的间隔小时数。 |
| `--headful` | 开启有头模式，显示浏览器窗口，主要用于开发调试。 |

## 🚀 常用命令示例

请在终端（如 PowerShell）中进入项目目录执行以下命令：

```powershell
cd C:\ai\softwares\tariff-scrape

# 1. 查询支持的省份列表名称
node tariff-query.js --list-provinces

# 2. 查询上海与江苏的套餐，取前10条，生成文本报告并导出 JSON（自动触发多省对比）
node tariff-query.js -p 上海市 -p 江苏省 --top 10 --out report.txt --json

# 3. 只查看江苏省的本地特有套餐
node tariff-query.js -p 江苏省 --local-only

# 4. 开启常驻模式，每 12 小时自动跑一次（按 Ctrl+C 停止）
node tariff-query.js -p 上海市 -p 江苏省 --out report.txt --watch

```

## 🧠 数据解析与对比逻辑

### 1. 资费精细化分类

脚本抛弃了粗略的“长期/活动”分类，采用更具实操意义的“主套餐 / 流量包”分类机制：

* **主套餐**：能作为手机号主资费独立办理的完整套餐（例如：直播神器卡、智臻会员、全球通、全家享、动感地带各卡、花卡、骑士卡等）。
* **流量包/附加包**：不能作为主资费独立存在，必须叠加在主套餐上，或属于充值/权益类的优惠。
* *识别关键词*：流量包、流量活动、享流量、优惠购活动、新机体验、AI灵犀、融合包、预存、升档、全品类优惠、限时特惠、副卡、礼包、畅享包。



### 2. 多省份智能对比 (`--compare`)

* **触发条件**：当参数传入 $\ge 2$ 个省份时，报告末尾将自动附带对比表（单省查询不显示）。
* **对比表指标**：横向并排展示每个省的以下数据：
* 主套餐数 / 流量包数
* 主套餐·最低单价及对应套餐
* 全场最低单价及对应套餐


* **结论总结**：表格末尾会自动生成一行结论，直观指出**哪个省份拿下了全场最低单价，以及价格便宜了多少倍**。

## 💡 部署与定时运行建议（三个要点）

1. **内置定时**：使用 `--watch` 参数可让 Node.js 进程常驻后台，利用 `setInterval` 循环执行。
2. **系统级定时（推荐）**：如果是为了在服务器或本地电脑上长期稳定运行（比如开机自启、不怕进程意外崩溃），建议**放弃使用 `--watch**`。
3. **任务计划程序**：更靠谱的做法是使用 Windows 系统自带的“任务计划程序”（Task Scheduler）或 Linux 的 `crontab`，定时调用完整的命令（例如 `node C:\ai\softwares\tariff-scrape\tariff-query.js -p 上海市 -p 江苏省 --out report.txt`），这样不仅节约系统资源，且容错率极高。
